<Callout>
  <p>The site is built from <strong>24 components</strong> — pieces designed once and reused everywhere. Editing a component changes every instance of it across all 16 pages. That is the point, and it is also the risk.</p>
</Callout>

## How components work here

A component has **variants** — alternate states of the same thing. The Button has CTA, Secondary, and Tertiary. The FAQ Item has Closed and Open. Placing a component gives you an **instance**, and each instance picks its variant and fills in its own text or link through **controls** in the right panel.

This means the same accordion design drives 22 FAQs across five pages, and one Button design covers every call to action on the site.

<Callout>
  <p><strong>Editing an instance vs editing the component.</strong> Changing text or a link on an instance is safe and local. Double-clicking through into the component itself edits the master — every instance everywhere changes. If you only meant to fix one, you probably wanted a control, not the component.</p>
</Callout>

## CMS-connected components

These pull their content from the CMS. Editing the copy means editing the collection item, not the component. See the [Using the Framer CMS](../using-the-framer-cms/) doc.

| Component | Variants | Reads from |
| --- | --- | --- |
| **Updates Feed** | All, Product, Company, Insights | Updates. Each variant filters the list to one category — that is how the chips on `/updates` work, with no code. |
| **Update Row** | Row | Updates. One row of the feed. Holds the hover state for the whole row in one place. |
| **FAQ Block** | Products, Why JustiFi, Vertical Software, Insurtech & MGA's, Franchise Networks | FAQs. One variant per page, each filtered to its category. |
| **FAQ Item** | Closed, Open | FAQs. A single question row inside the block. |
| **Customer Story** | Expanded, Collapsed | Customers. The case study card used on `/customers` and on all three solutions pages. |
| **Customer Stories** | First / Second / Third / Fourth Open | Customers. The multi-story accordion. |

## Where the FAQ Block sits

One instance per page, each on its matching variant:

- `/products` → Products
- `/why-justifi` → Why JustiFi
- `/solutions/vertical-software` → Vertical Software
- `/solutions/insurtech-mga` → Insurtech & MGA's
- `/solutions/franchise` → Franchise Networks

To put FAQs on a new page: add a category to the FAQs collection, add a matching variant to FAQ Block, filter its list to that category, and place an instance.
