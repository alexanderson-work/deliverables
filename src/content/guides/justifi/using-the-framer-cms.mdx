## How the CMS works

Three ideas:

- A **collection** is a content type — a table of the same kind of thing. This site has four.
- An **item** is one row: one update, one customer, one FAQ.
- A **field** is one column: a title, a date, a rich-text body.

The design pulls from those fields in two ways:

- **Detail pages** — a template page like `/updates/:slug` is designed once and rendered for every item.
- **Collection lists** — a repeating list on a page (the updates feed, the FAQ accordion) that pulls in items and can be filtered.

Find it all under the **CMS** tab in the left panel.

## The four collections

### Updates — 14 items

Product releases, company news, and editorial posts. Feeds the `/updates` index and generates a detail page per item at `/updates/:slug`.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |

| Summary | Text | Yes | Shown under the headline on the detail page |
| Category | Option | — | Product, Company, or Insights. Drives the filter chips. |

### FAQs — 22 items

Feeds the FAQ Block at the bottom of five pages. Has **no detail page** — these only ever appear inside an accordion.

| Field | Type | Notes |
| --- | --- | --- |
| Question | Text | The accordion header |
| Answer | Text | The revealed answer |
| Category | Option | Products, Why JustiFi, Vertical Software, Insurtech & MGA's, Franchise Networks |

**Category is what routes each question to a page.** The FAQ Block on `/products` shows only items tagged Products, the block on `/why-justifi` shows only Why JustiFi, and so on. To add a question to a page, create the item and set its Category — nothing on the page itself needs touching.

<Callout>
  <p>The current 22 FAQs are <strong>drafted placeholders</strong>. They should be reviewed and replaced with approved copy before launch — particularly anything touching compliance, PCI, registered-PayFac status, or go-live timing.</p>
</Callout>

### Legal — 3 items

Merchant Agreement, Terms of Service, and Privacy Policy. Rendered at `/legal/:slug` and linked from the footer. Fields: Title, Summary, Last Updated Date, Body (rich text), Slug.

## Adding or editing an item

1. Open the **CMS** tab and pick the collection.
2. **New** to add an item, or click an existing row to edit it.
3. Fill the fields. Anything marked required must have a value before the item will render properly.
4. Check the **Slug** — see the warning below.
5. **Publish** the site. CMS changes are not live until you publish, the same as design changes.

<Callout>
  <p><strong>Changing a Slug on a published item breaks its URL.</strong> The old address will 404 and any external link or search result pointing at it dies. If you must rename one after launch, add a redirect from the old path under Site Settings.</p>
</Callout>

## Two things to know about ordering

- **The Updates feed is in manual order.** It is not sorted by Date automatically. New posts land at the bottom of the collection and have to be dragged to the top, or a sort set on the list itself.
- **Category filtering is built into the components**, not into the collection. The Updates Feed component has one variant per category and the FAQ Block has one per page. If you add a new category to either collection, someone needs to add a matching variant for it to appear anywhere.
